# CodeHog — Duolingo для Python

Тренажёр Python с игровой механикой. Живёт на **https://maks.my**

```
лендинг → тест на уровень (без регистрации) → регистрация → личный курс
   → уроки с проверкой кода → монеты → колесо → магазин скинов ежа
```

## Запуск локально

```bash
cp .env.example .env      # вписать EXPLABS_API_KEY и ADMIN_PASSWORD
bash run.sh               # http://127.0.0.1:8000
```

## Из чего состоит

| Слой | Файлы |
|---|---|
| Модели (13 таблиц) | `app/models/` — user, learning, game, admin |
| Бизнес-логика | `app/services/` — economy, sandbox, course, testbank, ai, admin, i18n |
| HTTP | `app/api/` — pages (страницы), actions (JSON), admin (панель) |
| Интерфейс | `app/templates/`, `app/static/` |

### База: 13 таблиц

`users` · `daily_activity` · `coin_transactions` · `test_attempts` · `courses` ·
`modules` · `lessons` · `tasks` · `submissions` · `items` · `inventory` ·
`wheel_spins` · `bonus_grants`

### Ключевые решения

- **Код учеников исполняется в отдельном процессе** (`services/sandbox.py`) с лимитами CPU,
  памяти и времени. Запрещены импорты системных модулей, `eval`, `exec`, `open`.
  Для публичного сервиса этого мало — нужен контейнер без сети.
- **Курс генерирует модель, но структуру задаём мы.** Каркас тем — в `services/curriculum.py`,
  модель наполняет один урок за вызов. Всё сгенерированное проверяется: типы заданий,
  наличие ответов, а для задач на код — **реальный прогон эталонного решения в песочнице**.
  Не прошло — берётся шаблонный урок.
- **Первый урок отдаётся мгновенно** из шаблона, следующие готовятся в фоне
  (`services/prefetch.py`). Иначе человек ждал бы 20 секунд на генерации.
- **Наполнение урока защищено уникальным индексом** `(lesson_id, order_index)`:
  фоновый поток и запрос пользователя могут взяться за один урок одновременно.
- **Баланс монет — кеш, источник истины — журнал** `coin_transactions`.
- **Приз колеса определяет сервер** (`secrets.randbelow`), браузер только рисует анимацию.
  Повторный запрос за ту же веху возвращает прежний результат.

## Экономика

| Событие | Монеты |
|---|---:|
| Урок (первые 3 в день) | 10 |
| День с занятием | 15 |
| Каждые 7 дней подряд | 35 |
| Колесо (каждые 5 уроков) | 10–150, в среднем 24 |

Проверено симуляцией: 30 дней по 3 урока → около 2000 монет. Первая вещь (40) доступна
в первый день, хог-мобиль (1800) — примерно за месяц.

## Админ

Логин `maks-admin`, пароль из `ADMIN_PASSWORD`. Панель — `/admin`, скрыта от остальных (404).

Умеет: аналитику по воронке и пользователям, начисление бонуса всем сразу
(упадёт при следующем заходе), выдачу всех скинов себе, прохождение всего курса одной кнопкой,
сброс себя или любого пользователя. Монеты у админа не списываются.

## Языки

Русский по умолчанию, английский и чеченский (`services/i18n.py`).
Непереведённые строки показываются по-русски, поэтому язык добавляется без риска.
