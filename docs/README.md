# Проектная документация CodeHogwarts

Учебный проект по дисциплине «Объектно-ориентированное программирование», 2 семестр.
Клиент-серверное веб-приложение: игровой тренажёр программирования на Python.

**Рабочий стенд:** https://maks.my/codehog/

## Готовые файлы для сдачи

| Файл | Что это |
|---|---|
| **CodeHogwarts-документация.docx** | Всё одним документом Word, с оглавлением и диаграммами |
| **CodeHogwarts-документация.md** | То же в Markdown |
| `собрать-документ.py` | Пересобирает оба файла после правок |
| `диаграммы/` | Диаграммы в PNG (отрисованы из Mermaid) |

```bash
python3 собрать-документ.py     # после любой правки в документах
```

## Отступления от стека по умолчанию

1. **Технологический стек.**
   В методичке перечислены React/Vue/Flutter, ASP.NET Core + Entity Framework,
   PostgreSQL/MSSQL. У нас Python + FastAPI + SQLAlchemy + SQLite + ванильный JS.
   Методичка допускает расширение стека по согласованию с преподавателем —
   обоснование в [03-архитектура.md](03-архитектура.md#почему-такой-стек).

2. **SQLite вместо PostgreSQL.** Методичка разрешает SQLite «с объяснением необходимости».
   Объяснение и условия миграции — в [03-архитектура.md](03-архитектура.md#база-данных)
   и [07-риски.md](07-риски.md).
