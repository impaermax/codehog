# Версия 2 дизайна

Первый экран: **https://maks.my/v2/**
Магазин: **https://maks.my/v2/shop.html** — открывается рядом с текущей, ничего не ломая.

## Что здесь

| Файл | Что это |
|---|---|
| `ДИЗАЙН-СПЕЦИФИКАЦИЯ.md` | Полный арт-дирекшн от Astra: токены, типографика, сетка, компоненты, все экраны |
| `index.html` | Первый экран, собранный по спецификации |
| `css/style.css` | Токены и вёрстка |

| `img/предметы/*.png` | Девять вещей магазина в едином стиле |
| `img/hog-*.png` | Персонаж во всех вещах, фон вырезан |
| `vid/*.mp4` | Зацикленные анимации состояний |
| `генерация-скинов.sh` | Пересоздаёт виды персонажа от базового кадра |
| `генерация-видео.sh` | Пересоздаёт анимации и делает из них петли |
| `убрать-фон.py` | Вырезает фон заливкой от краёв |

## Чем отличается от текущей версии

| Было | Стало |
|---|---|
| Заголовок рвётся на «кибер-» / «ежа.» | Три управляемые строки, неразрывный дефис U+2011 |
| Три мелкие видеокарточки справа | Один крупный ёж на платформе + три вкладки состояний |
| Бирюзовое свечение у кнопки, карточек и текста | Акцент только у действия и энергии персонажа |
| Три серых прямоугольника внизу | Единый маршрут: определи уровень → получи курс → прокачивай |
| Логотип из эмодзи | Собственный знак |
| Системный шрифт | Golos Text + JetBrains Mono |
| Один радиус 16px у всего | 4 / 8 / 12 / 16 px по роли элемента |
| Подписи «в тренде», «люкс» | «01 / База», «02 / Неон», «03 / Хог-мобиль» — ступени прогресса, а не товар |

## Про вырезание фона

Обычный `colorkey` в ffmpeg съедал чёрное худи: оно почти совпадает с фоном по цвету.
`убрать-фон.py` заливает прозрачностью только те пиксели, что связаны с рамкой кадра,
поэтому одежда остаётся целой.

```bash
../.venv/bin/python убрать-фон.py ../app/static/img/hog-base.png img/hog-base.png
```

## Магазин

Девять предметов сгенерированы одним промптом-хвостом, поэтому кепка, рюкзак и лофт
выглядят одним набором, а не случайной подборкой.

Виды персонажа сделаны **image-to-video от базового кадра** — ёж остаётся тем же,
меняются только вещи. Клик по картинке товара примеряет её на персонажа;
у скинов, транспорта и домов вместо статичной картинки запускается анимация.

| Вещь | Вид персонажа | Анимация |
|---|---|---|
| Неоновая кепка | `hog-cap.png` | — |
| Очки отладки | `hog-glasses.png` | — |
| Худи Python | `hog-base.png` | `vid/base.mp4` |
| Рюкзак разработчика | `hog-backpack.png` | — |
| Неоновые иглы | `hog-neon.png` | `vid/neon.mp4` |
| Хромированный ёж | `hog-chrome.png` | `vid/chrome.mp4` |
| Хог-мобиль | `hog-car.png` | `vid/car.mp4` |
| Капсула кодера | `hog-capsule.png` | `vid/capsule.mp4` |
| Кибер-лофт | `hog-loft.png` | `vid/loft.mp4` |

Плюс `hog-full.png` и `vid/full.mp4` — ёж во всём сразу.

### Про фон у видео

У mp4 нет альфа-канала, поэтому в примерке ролик шёл тёмным прямоугольником поверх сцены.
Лечится наложением `mix-blend-mode: lighten`: фон сцены светлее подложки ролика и побеждает,
а персонаж остаётся. Перегенерация не нужна.
